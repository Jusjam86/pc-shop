# PC Shop Application
### About
This Java terminal application allows you to customize your pc with different parts the way you want it or choose a pre-build that'll save you the hassle of building a pc because why not. 
You can accessories and peripherals to your order as well as adding an RGB lighting upgrade to make your pc look pretty or cool, or even better... pretty cool~
## Features
- **Build PC**: you can build your pc from scratch using the four different form factors and from there you can choose each individual parts that fit your build in your mind.
You can also choose a pre-build to purchase if you just want a pc that you know will work and get the job.
- **Adding Accessories**: the user is able to choose from a small list of pc accessories that'll ensure your future pc will have everything it needs 
- **Adding Peripherals**: the user can choose from a wide list of peripherals ranging from monitors, mouse pads, keyboards, etc.
- **The Cart**: in the cart, you can view what you have before making a purchase or remove items you no longer need
- **Checkout**: after making a purhcase, it will make and save a copy of your receipt and you can immedietly view it
- **Receipt/ past receipts**: user can see past orders made from before with an accurate list and pricing of each item
## Interesting Code
- I'm very proud of my enum classes after learning what they are and how they work. Being able to define my four pc types and form factors with fixed values helps a lot knowing that it acts
as the base for my builds and only adds on top of whats there instead of changing it entirely.
- Enums are a special data type that defines a fixed set of named constants and they're used when a variable should only hold one of a predefined set of values.
The key advantage I learned about enums over plain constants is that enums are full-fledged classes in Java that can implement interfaces, have abstract methods, and carry behavior alongside their values.
